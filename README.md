Repository ini berisi penyelesaian tugas logika penyelesaian masalah untuk dua problem:
The Last Astronaut — simulasi eliminasi astronot secara melingkar (modifikasi Josephus Problem) dengan nilai K yang berubah dinamis setelah setiap eliminasi berdasarkan paritas nomor astronot yang tereliminasi.
Alien-In-The-Middle — sistem sandi substitusi, setiap huruf digeser berdasarkan posisi alfabet huruf asli sebelumnya, dengan aturan modulo 26.
Fase 1: logika penyelesaian dalam bentuk pseudocode dan flowchart beserta penjelasan.
Fase 2: implementasi kedua solusi dalam C++, hanya menggunakan library iostream dengan seluruh fungsi dibuat manual (user-defined function).
